# Ghoti Hermes Productivity Setup

Hermes is a cheap local coordinator, memory compressor, handoff summarizer,
tool-status digest, and next-action reporter. It is not the final authority and
does not execute.

Use `23_configs/assistant_productivity/hermes_productivity.example.json` and
`14_context/assistant_productivity/hermes_ready_prompts.md`.

## Read order

1. Latest committed Agent OS and operator evidence.
2. Compact memory and Obsidian vault.
3. Current handoffs and branch reports.
4. Tool-stack, MCP, skills, and Ruflo productivity configs.

Every summary must preserve source paths, conflicting SHAs, failed checks,
uncertainty, and the next human-approved action. Provider setup, Telegram,
browser/computer-use, account actions, and command execution stay blocked.
