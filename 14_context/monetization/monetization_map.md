# Monetization Map

Ideas mapped to a concrete first-dollar path, ranked by speed-to-first-money.
All compliant; the human handles payments and accounts.

| Rank | Offer | Model | Who pays | First-dollar path |
|------|-------|-------|----------|-------------------|
| 1 | Paid template / Whop product | one-time | buyer | author template -> human lists -> first sale |
| 2 | Design / front-end gig | one-time/project | client | portfolio page -> 1 client -> deliver |
| 3 | AI automation plan | project + retainer | SMB client | automation plan + demo -> 1 client |
| 4 | Compliant research report | one-time | client | cited report sample -> 1 paid report |
| 5 | Analytics / GEO dashboard | recurring | site owner | set up privacy analytics -> monthly fee |
| 6 | Content/clipping package | retainer | creator/brand | drafted package -> 1 retainer |
| 7 | Lead-gen (opt-in) | retainer | SMB | opt-in list + drafts -> 1 retainer |
| 8 | Email funnel (Listmonk) | project + retainer | SMB | welcome sequence -> 1 client |

Recurring beats one-time for stability; start with one-time offers (1-2) for
the fastest first dollar, then convert to retainers (5-8). No spam, no fake
engagement, no autonomous spend.
